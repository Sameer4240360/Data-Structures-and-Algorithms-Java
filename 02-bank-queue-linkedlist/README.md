# 02 - Bank Priority Queue (Linked List)

The same ABC Bank problem as project 01, solved with a **singly linked list** that is kept sorted by priority.
Priority order and the automatic VIP/VVIP upgrade rules are the same.

**Menu:** add customer, serve customer, display all, eldest customer, youngest female,
female VVIPs, female Normals, eldest VIP, search by name, average age of VVIPs.

## Run
```bash
javac -d out 02-bank-queue-linkedlist/src/bankqueuelinkedlist/*.java
java -cp out bankqueuelinkedlist.Main
```
