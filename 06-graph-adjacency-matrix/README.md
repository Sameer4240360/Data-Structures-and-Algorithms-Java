# 06 - Transportation Network (Graph, Adjacency Matrix)

Cities are nodes and routes are edges of an undirected **graph** stored in an **adjacency matrix** (up to 50 cities).

**Menu:** add city, add route, search the routes of a city, check for a direct route between two cities,
delete city, delete route, DFS traversal, BFS traversal.

## Run
```bash
javac -d out 06-graph-adjacency-matrix/src/graphmatrix/*.java
java -cp out graphmatrix.Main
```
