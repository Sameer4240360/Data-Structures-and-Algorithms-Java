# 07 - Social Network (Graph, Adjacency List)

Users are nodes and friendships are edges of an undirected **graph** stored with **adjacency lists**
(linked lists), so there is no fixed limit on the number of users.

**Menu:** add user, add friendship, search the friends of a user, check for a direct friendship,
delete user, delete friendship, DFS traversal, BFS traversal.

## Run
```bash
javac -d out 07-graph-adjacency-list/src/graphlist/*.java
java -cp out graphlist.Main
```
